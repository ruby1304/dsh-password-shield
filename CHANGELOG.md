# Changelog

## 0.3.0 - 2026-08-20

- Remove the earlier password-field rewriting behavior entirely.
- Match only the public iCloud Passwords extension origin and its completion-list resource.
- Keep password, API-key and ordinary text inputs untouched.
- Add reproducible CI, CodeQL, repository privacy checks and npm provenance publishing.

## 0.2.0 - 2026-08-17

- Add the iCloud Passwords completion-list popup guard.

## 0.1.0 - 2026-08-17

- Initial experiment that rewrote password-type fields. This behavior was removed in 0.3.0 and is no longer supported.
